## 配置

仓库的 `Settings` - `Actions secrets and variables` -> `Repository secrets`

- `GIT_USERNAME`

- `ISSUSE_TOKEN`：用于拉取代码

  可在 settings - `Developer Settings` -> `Personal access tokens` -> `Generate new token` 生成

- `REPO_NAMES`：仓库名称，多个用 `;` 隔开，比如 "test1;test3"
